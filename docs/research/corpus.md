# 真实语料基线

语料本身不进仓库，只记统计结果。当前基线是 2026-11 的原始 LRC 快照；更早的
统计保留在「历史快照」下，不能从当前语料复现。

统计脚本 [`tools/corpus_stats.py`](../../tools/corpus_stats.py)，复现方式：

```powershell
uv run python tools/corpus_stats.py <corpus-dir>
```

### 解读

- 原文 536 / 1448（37%）含逐字标签；译文没有逐字标签，逐字数据只在原文侧。
- 原文 0 空行，译文 78 行空行；空行不是这份快照的主要形态。
- 2 位尾数很常见：36,031 个 2 位标签对 131,110 个 3 位标签；纯 2 位文件 763 个。
- 127 个文件用 `[mm:ss:cc]`；没有真小时标签。
- 多行首标签 144 行，分布在 12 个文件；抽查这些行没有逐字标签，时间差大多超过
  15 秒，按重复行简写读。
- 注释只有 2 行 / 1 个文件，`[offset:]` 只有 1 个文件；这两种形态在真实语料里
  很少。
- 解析异常、validate error、行级往返不一致都是 0；报告里只有
  `end-marker-ignored` 和 `orphaned-line`。
- 译文与原文的时间戳大多完全对齐：1421 / 1448 对全部对齐，26 对部分对齐，0 对
  完全对不上。需要模糊匹配的场景集中在少数文件。

## 历史快照：6536 份 / 33 万行

以下数字来自更早的语料快照，不能从当前语料复现；保留作为当时取舍的依据。

| 指标 | 数值 |
| --- | --- |
| 解析异常 / `validate()` 问题 / 往返不变量违例 | 0 / 0 / 0 |
| 含 metadata 的文件 | 410（`by` 388、`ti` 32、`ar` 29、`al` 22、`offset` 12，`re` / `ve` / `ly` / `mu` / `total` / `length` / `tool` 各 1） |
| 逐字行 / 带尖括号标签的文件 | 1666 行 / 71 个文件 |
| 首词元晚于行首的行 | 296 |
| 相邻时间标签相等 / 递减 | 1917 / 0 |
| 行首重复（完全相同）的标签 | 0 |
| 时间标签尾数位数 | 3 位 547427，2 位 39266 |
| 写回后与源文件字节不同 | 6536（100%） |

各项支撑的取舍：

- 相等 1917、递减 0：相等标签只记 debug，递减才告警。
- 首词元晚于行首 296 行：`use_bracket_for_byword_tag=True` 在真实数据上确实会让
  这些行读回两行，不是理论问题。
- 写回 100% 不同（CRLF 变 LF、2 位尾数补成 3 位、行间空行）：行尾可以通过
  `line_ending` 显式保留；其余属于写回时的规范化，不随源文本保留，见
  [semantics.md](../design/semantics.md#序列化输出)。
- 行尾：6633 份全部是 CRLF，没有 LF 或混用；其中 5 份末尾没有换行。（2026-10，
  同一曲库的较新快照。）
- 非标准 key（`ly` / `mu` / `total` / `tool`）：metadata 只做类型提示，不校验
  key 是否"标准"。
