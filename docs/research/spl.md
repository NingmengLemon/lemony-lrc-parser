# SPL 对照

[SPL](https://moriafly.com/standards/spl.html)（Salt Player Lyrics，制定于
2024-12-16，当前对照的是 2026-09-19 修订版）是目前唯一把 LRC 家族多年踩到的
兼容性问题写成条文的文档，本库把它当 LRC 语义的参照物。逐条用例在
[`tests/test_spl_conformance.py`](../../tests/test_spl_conformance.py)。

## 一致的部分

时间戳数字规范、显式与隐式行尾、空正文行是纯结束标记、重复行简写、翻译的
三种识别方式、`[...]` 与 `<...>` 两种逐字写法、延迟首字
`[05:20.22]<05:21.22>你好[05:24.22]`、越界逐字标记忽略。

## 空正文行

SPL 原文："时间戳后不接任何文本内容的行是纯粹的结束标记：它不会产生一句新歌词，
也不参与翻译识别……结束标记行常与下一句歌词使用相同的时间戳"。

6622 份文件（58.6 万非空行）的统计：

| 指标 | 数值 |
| --- | --- |
| 空正文行（方括号标签之后完全为空） | 28836 |
| 能找到开始时间更早的上一行（可当行尾） | 28279 |
| 下一非空行的行首标签与之相同 | 1458 |
| 若读成空行，会把下一句真实歌词挤成翻译 | 420 处，138 个文件 |
| 标签之后只剩空白的行 | 0 |
| 一行上有多个标签的空行 | 0 |

按 SPL 读法，上面 420 处全部正确，28436 行拿到真实的 `end`。

## 有意偏离

| 项 | SPL | 本库 | 语料 |
| --- | --- | --- | --- |
| 分钟位数 | 1-3 位 | 1-4 位 | 无 4 位 |
| 尾数 4-6 位 | 字面毫秒（`450000` 是 450000ms） | 秒的小数部分，截断到毫秒（450ms） | 0 例 |
| 标签后只剩空白 | 未定义 | 算正文 | 0 例 |
| `[行标签][首字标签]文本` | 按重复行读（"局限性"一节） | 标签非递减时按首字延迟读成一行 | 199 行 / 20 文件，197 行两标签相差 0.1-1.3 秒 |
| 隐式行尾 | 默认持续到下一行开始 | 默认 `end=None`，可选填充 | — |
| 空正文行 | 不存在这种行 | 整行只有尖括号标签时保留，承载空字幕 cue | 0 例 |

尾数 4-6 位这一条，标准内部本身有歧义：既然"不足 3 位视为在后位省略 0"
（`1` 是 100ms），`450000` 也可以读成 0.450000 秒。两种读法差 1000 倍，本库取
后者，并用测试固定。

收到与这张表相关的 bug 报告时先对照：多数是标准本身有歧义，或者真实语料另有
共识。要改其中任何一条，先补语料统计。
